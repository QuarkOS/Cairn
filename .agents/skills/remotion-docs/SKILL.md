## Documentation

To look up documentation for a Remotion API, use the `remotion-dev` MCP server.

## Changelog

To look up the changelog for Remotion, load the following URL:

```
https://www.remotion.dev/changelog.md
```

If you want to read about a specific release, load the following URL:

```
https://www.remotion.dev/changelog/<version>.md
```

For example, for Remotion 4.0.420, load:

```
https://www.remotion.dev/changelog/4.0.420.md
```

## Templates

To look up the list of templates, load the following URL:

```
https://www.remotion.dev/templates.md
```

To get details about a specific template, load the following URL:

```
https://www.remotion.dev/templates/<slug>.md
```

For example, for the Hello World template, load:

```
https://www.remotion.dev/templates/hello-world.md
```
